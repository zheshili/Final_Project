\# AMS 561 Final Project: Simplified Replication of Rust (1987)



This repository contains the final project for AMS 561 at Stony Brook University.



The project replicates a simplified version of Rust (1987), a dynamic discrete choice model of bus engine replacement. The repository includes Python code, output tables, figures, the final report, and presentation slides.



\## Repository Contents



\- `rust\_replication\_simplified\_v2.py`: main Python replication code.

\- `rust\_replication\_outputs\_simplified/`: generated estimation tables and figures.

\- `AMS\_561\_Project\_Proposal.pdf`: project proposal.

\- `A\_Simplified\_Replication\_of\_Rust\_1987.pdf`: final report.

\- `AMS\_561\_Final\_Project\_Presentation.pdf`: presentation slides.

\- `rust\_1987.pdf`: original paper.
