\# Replication Outputs



This folder contains the tables and figures generated by `rust\_replication\_simplified\_v2.py`.



The main outputs include:



\- Estimation results table.

\- LM-style specification test table.

\- Heterogeneity likelihood-ratio test table.

\- Conditional choice probability figures.

\- Value function and replacement probability figures.



These files are generated by running the main Python replication script.
